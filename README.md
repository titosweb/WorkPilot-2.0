# WorkPilot Hub

Build WorkPilot AI, a production-quality modern SaaS workplace productivity dashboard. Implement the complete integrated frontend experience described: shared sidebar/header/mobile nav and coherent design system; Dashboard; Smart Email Generator; Meeting Notes Summarizer; AI Task Planner; AI Research Assistant; AI Workplace Chat; Responsible AI; Settings. Use clearly labelled demo/mock and empty/loading/error/success states where no live AI is connected, never present mock output as real AI. Architect each module around modular dedicated system prompts suitable for later real AI/API integration, preserving human oversight and no-fabrication requirements. Prioritize polished responsive UX, accessibility, maintainable architecture, professional enterprise SaaS look, editable/copy/regenerate/clear interactions, and prominent responsible-AI disclaimers on generated content.
